# Bildmarke

Der Pfad in `mark-path.txt` ist die Bildmarke des FORTH-TRACE-Systems:
Dolch mit Ringknauf, viewBox `0 0 166.6 908.7`, Verhaeltnis rund 1:5,45.

Aus `assets/logo/mark.svg` des Design Systems uebernommen, ohne die
C2PA-Provenienzdaten. Laut System ist dieser Pfad massgeblich und wird
**nicht nachgezeichnet**. Mindesthoehe 64 px, darunter schliesst sich das
Ringloch. Zulaessige Farben: Sage, Weiss, Ink.

`tools/make-icons.mjs` erzeugt daraus alle App-Symbole und Splash-Bilder,
`dist/index.html` traegt ihn inline in der Kopfzeile.
